# x402 Machine Economy

PowerChain can monetize solar forecasts, weather, grid congestion, routing, verified meter data, battery optimization, charging availability, carbon data, and agent services through x402.

```text
Agent → PowerChain API → HTTP 402 → Payment Requirements → Policy / Spend Controls → Payment → Service Response
```

Policies constrain payees, networks, assets, maximum payment, daily budget, and allowed services.
