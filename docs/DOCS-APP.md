# Documentation Application

`apps/docs` is the canonical Next.js documentation surface for PowerChain Local Energy OS v1.0.0.

It consumes `@powerchain/shared` for documentation metadata and `/components/docs` for presentation. The docs app intentionally remains read-focused and separate from the operational Energy, Platform, Grid, Plants, Wind, Charging, Companies and Supply Chain applications.

Routes include architecture, SaaS, API, Energy RWA, PWRC/wPWRC, protocols, shared primitives, storage and application-state guidance.
