# Supply Chain and Asset Passports

```text
Manufacturer → Production → Shipment → Warehouse → Installer → Energy Site → Commissioning → Operation → Maintenance → Retirement → Recycling
```

Supported infrastructure includes solar panels, inverters, turbines, batteries, EV chargers, smart meters, transformers, switchgear, and gateways. Blockchain commitments reference evidence; they do not replace enterprise source data.
