# Protocol Boundaries

- Smart metering: DLMS/COSEM
- IoT: MQTT
- Industrial: OPC UA / Modbus / IEC 61850 adapters
- EV backend: OCPP 2.1
- EV/EVSE: ISO 15118-20
- Roaming: OCPI 2.3.0
- Demand response: OpenADR
- Grid topology: IEC CIM
- Supply chain: GS1 EPCIS 2.0
- Machine payments: x402
- Stablecoin cross-chain: CCTP adapter
- Oracles: Pyth primary + Chainlink fallback/CCIP adapter
- Solana execution: SVM adapter; optimized programs may use Pinocchio
- Solana asset identity: Metaplex adapter
- Sui execution: Move object adapter
