# PowerChain Copilot Skills

PowerChain skills are bounded, auditable capabilities exposed to AI agents.

## Renewables
- Forecast solar and wind generation.
- Compare actual production with forecast bands.
- Identify curtailment and availability anomalies.

## Grid Operations
- Summarize telemetry and incident context.
- Recommend operator-reviewed remediation steps.
- Never issue autonomous switching commands.

## Markets
- Explain PWRC, CRT, REC and energy-market positions.
- Prepare draft orders; a user signature is always required for settlement.

## Security
- Respect tenant boundaries and RBAC.
- Redact secrets, private keys and credentials.
- Log tool calls with correlation IDs.
