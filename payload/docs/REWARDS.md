# PWRC Reward Epochs

Rewards are distributed through explicit epochs and remain separate from physical-energy accounting.

```text
Verified Contribution → Score → Epoch → Allocation → Claim → PWRC
```

The reward score can incorporate verified energy, quality, reliability, and policy weight. No fixed `1 kWh = 1 PWRC` rule is implied.

Finalized allocations receive a deterministic allocation root for audit and on-chain commitment.
